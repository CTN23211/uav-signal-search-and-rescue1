# Public release checklist

Before changing the GitHub repository from Private to Public:

- confirm no private credentials, tokens, Wi-Fi passwords or SSH keys are present;
- confirm model / dataset redistribution rights;
- confirm team / competition ownership of custom source;
- preserve upstream attribution for EGO / Fast-Drone-250;
- do not claim a from-scratch EGO implementation;
- confirm any repository-wide license decision with ownership constraints;
- remove raw logs, bags, PCDs and large binary models;
- review demo footage for unintended personal / location information.

V3 was curated to remove obvious generated artifacts and deployment-specific absolute personal paths, but a human pre-publication review is still recommended.
