# Demo media

Demo videos are intentionally not committed in this source archive.

Recommended public portfolio layout:

1. **Indoor complete run** — synchronized aircraft footage + RViz / ground-screen recording where available.
2. **Outdoor search run** — include the visible target / signal-source search sequence.
3. **Ground-station view** — RF points, search score / route generation, route dispatch and target-confirmation event.
4. **Planner safety clip** — optional short example showing the modified EGO real-flight behavior.

For GitHub, prefer short compressed media, release assets or external video links rather than committing raw multi-hundred-MB recordings to Git history.
